# Questions fréquentes des étudiants

## Peut-on rendre un TP en retard ?
Oui, avec une pénalité de 2 points par jour de retard. Aucun rendu n'est accepté par e-mail.

## Peut-on changer de binôme ?
Oui, jusqu'au rendu du TP2, en prévenant l'enseignant. Ensuite, les binômes sont fixés pour le reste du semestre.

## Où trouver les supports de cours ?
Sur Moodle, espace « SMA - M1 » : diapositives, énoncés, annale corrigée du partiel.

## Peut-on utiliser un autre langage que Java ?
Les TP se font en Java avec JADE. Pour le projet final, Python est accepté après accord de l'enseignant.

## Le rapport doit-il suivre un modèle ?
Un modèle LaTeX et un modèle Word sont disponibles sur Moodle. Le format PDF est obligatoire.

## J'ai été absent au partiel, que faire ?
Envoyer un justificatif à la scolarité dans les 48 heures ; la scolarité indique les modalités du rattrapage.

## Peut-on obtenir sa note par e-mail ?
Non. Les notes sont publiées uniquement sur l'ENT.
